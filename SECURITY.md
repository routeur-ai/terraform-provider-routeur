# Security policy

## Reporting a vulnerability

Please report security issues privately by email to
**security@routeur.ai**, not as a public GitHub issue or pull request.

Include what you found, how to reproduce it, the provider version, and the
impact you believe it has. Do not include real API tokens or provider
API keys; if one has been exposed, revoke it in routeur.ai first.

We will acknowledge your report, keep you updated while we investigate, and
credit you in the release notes if you wish.

## Supported versions

Security fixes are released for the latest version of the provider.
